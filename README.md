# Aarthic

This project focuses on predicting next-day stock price movement (Up/Down) using machine learning techniques applied to historical OHLCV data. Financial indicators such as RSI, MACD, volatility, volume trends, and lagged returns were used to capture market momentum and behavior. Multiple classification models were trained and evaluated, with Random Forest showing the best performance. The final model was deployed as an interactive Streamlit web application to demonstrate real-world usability.
